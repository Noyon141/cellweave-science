# Scientific Warnings / RUO

Warnings may include:
- low biological replicate count
- strong batch confounding
- high mitochondrial content
- large doublet fraction
- low annotation confidence
- insufficient cells
- reference organism mismatch

Warnings remain part of run provenance.

CellWeave is Research Use Only.
Scientific code/results must not become:
- diagnosis
- treatment recommendation
- clinical decision support

PHI workflows are prohibited.
